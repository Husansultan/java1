═══════════════════════════════════════════════════════════════════
СПОСОБ 1: СКАЧАТЬ ЧЕРЕЗ CURSOR (САМЫЙ ПРОСТОЙ)
═══════════════════════════════════════════════════════════════════

1. Посмотрите в ЛЕВУЮ БОКОВУЮ ПАНЕЛЬ Cursor (Explorer)
   Вы должны увидеть все файлы .mq5, .md, .txt

2. ПРАВОЙ кнопкой мыши на файл:
   → "Reveal in File Explorer" (Показать в проводнике)
   → Откроется папка с файлами

3. Скопируйте файлы отсюда на диск C:\

═══════════════════════════════════════════════════════════════════
СПОСОБ 2: СКАЧАТЬ АРХИВ
═══════════════════════════════════════════════════════════════════

1. Найдите файл: CrashBoom_Indicator_Files.zip
   В панели Explorer в Cursor

2. Скачайте или скопируйте этот ZIP-файл

3. Распакуйте на диск C:\

═══════════════════════════════════════════════════════════════════
СПОСОБ 3: КОПИРОВАТЬ ВРУЧНУЮ ИЗ CURSOR
═══════════════════════════════════════════════════════════════════

Если вы видите файлы в Cursor, но не можете их скопировать:

1. Откройте файл в Cursor (двойной клик)

2. Нажмите Ctrl+A (выделить всё)

3. Нажмите Ctrl+C (копировать)

4. Откройте Блокнот (Notepad) на Windows

5. Нажмите Ctrl+V (вставить)

6. Сохраните файл с правильным названием:
   - Для индикаторов: с расширением .mq5
   - Для документации: с расширением .md или .txt

═══════════════════════════════════════════════════════════════════
КУДА КОПИРОВАТЬ ФАЙЛЫ .MQ5 ДЛЯ MT5
═══════════════════════════════════════════════════════════════════

Скопируйте файлы .mq5 в папку:

C:\Users\[ВашеИмя]\AppData\Roaming\MetaQuotes\Terminal\[ID]\MQL5\Indicators\

Чтобы быстро найти эту папку:

1. Откройте MetaTrader 5

2. Меню "File" → "Open Data Folder"

3. Откроется папка → перейдите в MQL5\Indicators\

4. Скопируйте сюда файлы .mq5

═══════════════════════════════════════════════════════════════════
ЕСЛИ У ВАС WINDOWS И CURSOR НА ОДНОМ КОМПЬЮТЕРЕ
═══════════════════════════════════════════════════════════════════

Workspace Cursor обычно находится здесь:

Вариант 1:
В самом Cursor посмотрите путь workspace вверху окна

Вариант 2:
Файлы могут быть в:
C:\Users\[ВашеИмя]\workspace\

Вариант 3:
Посмотрите в настройках Cursor, где находится workspace

═══════════════════════════════════════════════════════════════════
БЫСТРАЯ УСТАНОВКА (ЕСЛИ ФАЙЛЫ УЖЕ НА ДИСКЕ C:\)
═══════════════════════════════════════════════════════════════════

1. Откройте MetaTrader 5

2. Нажмите F4 (откроется MetaEditor)

3. File → Open → найдите файл CrashBoom_Simple.mq5
   (на диске C:\ там, где вы его сохранили)

4. Нажмите F7 (Compile)

5. Должно появиться: "0 error(s), 0 warning(s)"

6. Закройте MetaEditor

7. В MT5 откройте график Crash или Boom

8. Navigator (Ctrl+N) → Indicators → Custom → CrashBoom_Simple

9. Перетащите на график

10. Готово! ✅

НУЖНА ПОМОЩЬ?
═══════════════════════════════════════════════════════════════════

Если не можете найти файлы:

1. Посмотрите в боковой панели Cursor слева (Explorer)
   Там должны быть видны все .mq5 файлы

2. Попробуйте скачать архив: CrashBoom_Indicator_Files.zip
   Он содержит все нужные файлы

3. В Cursor можно использовать команду "Download" на файл
   (правой кнопкой мыши)
