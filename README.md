# CrashBoom Impulse Detector для MetaTrader 5

## 🎯 Описание
Профессиональный индикатор для MetaTrader 5, предназначенный для анализа и прогнозирования импульсов (спайков) на синтетических индексах **Crash** и **Boom** от брокера **Deriv**.

## 🚀 Основные возможности
- ✅ **Комплексный технический анализ** с использованием 15+ индикаторов
- 🤖 **Система самообучения** с машинным обучением
- 🎨 **Визуальные сигналы** с цветными стрелками
- 🔔 **Многоуровневая система оповещений** (Alert, Push, Email)
- 📊 **Информационная панель** в реальном времени
- ⚙️ **Полная настраиваемость** всех параметров

## 📁 Файлы проекта
- `CrashBoom_ImpulseDetector.mq5` - Основной файл индикатора

## 🎯 Поддерживаемые символы
### Crash индексы
- Crash 150/300/500/600/900/1000 Index

### Boom индексы  
- Boom 150/300/500/600/900/1000 Index

## 🔧 Быстрая установка
1. Скопируйте `CrashBoom_ImpulseDetector.mq5` в папку `MQL5/Indicators`
2. Откройте MetaEditor и скомпилируйте файл (F7)
3. Примените индикатор к графику Crash/Boom
4. Настройте параметры по вашим предпочтениям

## 📈 Как работает
Индикатор анализирует:
- **Трендовые индикаторы**: EMA, Ichimoku, Parabolic SAR, Alligator
- **Осцилляторы**: RSI, MACD, Stochastic, Williams %R, CCI
- **Волатильность**: ATR, Bollinger Bands
- **Объемы**: OBV, MFI, тиковые объемы
- **Графические паттерны**: Фракталы, ZigZag, уровни поддержки/сопротивления

На основе комплексного анализа индикатор:
1. Рассчитывает вероятность появления импульса
2. Применяет алгоритмы машинного обучения для корректировки
3. Отображает стрелки за 1-5 баров до предполагаемого импульса
4. Отправляет оповещения трейдеру

## 🎨 Визуализация
- 🔴 **Красные стрелки** - сигнал Crash (падение)
- 🔵 **Синие стрелки** - сигнал Boom (рост)
- 📊 **Информационная панель** с текущими показателями
- ⚙️ **Настраиваемые цвета и размеры**

## ⚠️ Дисклеймер
Данный индикатор предназначен только для образовательных целей. Торговля на финансовых рынках связана с высокими рисками. Всегда тестируйте стратегии на демо-счете перед реальной торговлей.
