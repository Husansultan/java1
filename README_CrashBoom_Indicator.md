# CrashBoom Impulse Detector для MetaTrader 5

## Описание

Полнофункциональный пользовательский индикатор для платформы MetaTrader 5, предназначенный для анализа индексов Crash/Boom от брокера Deriv. Индикатор выполняет комплексный технический анализ и прогнозирует моменты появления импульсов (spikes) с высокой точностью.

## Возможности

### 🔍 Комплексный технический анализ
- **Трендовые индикаторы**: EMA (50/100/200), Ichimoku, Parabolic SAR, Alligator
- **Осцилляторы**: RSI, MACD, Stochastic, Williams %R, CCI, MFI
- **Волатильность**: ATR, Bollinger Bands, Keltner Channel
- **Объемы**: OBV, MFI, Tick Volumes
- **Bill Williams**: Alligator, Awesome Oscillator, Accelerator Oscillator, Fractals
- **Дополнительные**: ZigZag, Linear Regression, Standard Deviation

### 🎯 Прогнозирование импульсов
- Автоматическое определение моментов появления Boom/Crash spikes
- Прогнозирование за 1-3 бара до импульса
- Система самообучения для повышения точности
- Анализ дивергенций и паттернов

### 📊 Визуализация
- Стрелки на графике (🔵 Boom, 🔴 Crash)
- Текстовые метки с описанием сигналов
- Цветовая индикация направления
- Настраиваемые параметры отображения

### 🔔 Оповещения
- Звуковые сигналы (Alert)
- Сообщения в лог терминала
- Детальная информация о вероятности импульса
- Настраиваемые параметры оповещений

## Установка

### 1. Копирование файлов
1. Скопируйте файл `CrashBoom_ImpulseDetector.mq5` в папку `MQL5/Indicators/` вашего терминала MetaTrader 5
2. Скопируйте файл `CrashBoom_AdvancedAnalysis.mqh` в папку `MQL5/Include/`

### 2. Компиляция
1. Откройте MetaEditor (F4 в терминале)
2. Откройте файл `CrashBoom_ImpulseDetector.mq5`
3. Нажмите F7 для компиляции
4. Убедитесь, что нет ошибок компиляции

### 3. Установка на график
1. В терминале MT5 откройте график нужного символа (например, Crash 300 Index)
2. Перетащите индикатор из окна "Навигатор" на график
3. Настройте параметры в окне "Свойства"

## Настройка параметров

### Основные настройки
- **SpikeDetectionDepth** (20): Глубина анализа фракталов/ZigZag
- **SpikePredictionSensitivity** (0.7): Чувствительность определения импульса (0.0-1.0)
- **EnableAlerts** (true): Включить оповещения
- **Timeframe** (PERIOD_CURRENT): Таймфрейм анализа

### Скользящие средние
- **MovingAveragePeriod1** (50): Период EMA 1
- **MovingAveragePeriod2** (100): Период EMA 2  
- **MovingAveragePeriod3** (200): Период EMA 3

### Осцилляторы
- **RSI_Period** (14): Период RSI
- **MACD_Fast** (12): Быстрый период MACD
- **MACD_Slow** (26): Медленный период MACD
- **MACD_Signal** (9): Сигнальный период MACD

### Волатильность
- **ATR_Period** (14): Период ATR
- **Bollinger_Period** (20): Период Bollinger Bands
- **Bollinger_Deviation** (2.0): Отклонение Bollinger Bands

### Визуализация
- **ArrowSize** (3): Размер стрелки
- **ArrowDistance** (20): Смещение стрелки от свечи
- **ShowFibonacciLevels** (true): Показывать Фибо-уровни
- **ShowSupportResistance** (true): Показывать уровни поддержки/сопротивления

### Самообучение
- **EnableMachineLearning** (true): Включить самообучение
- **LearningPeriod** (100): Период обучения
- **LearningRate** (0.1): Скорость обучения

## Поддерживаемые символы

Индикатор работает с индексами Deriv:
- **Crash**: 150, 300, 500, 600, 900, 1000 Index
- **Boom**: 150, 300, 500, 600, 900, 1000 Index

## Алгоритм работы

### 1. Сбор данных
- Получение данных всех технических индикаторов
- Анализ ценовых данных и объемов
- Построение графических объектов

### 2. Комплексный анализ
- **Анализ тренда**: EMA, Ichimoku, Alligator, Parabolic SAR
- **Анализ волатильности**: ATR, Bollinger Bands
- **Анализ моментума**: RSI, MACD, Stochastic, Williams %R, CCI
- **Анализ объемов**: OBV, MFI, Tick Volumes
- **Анализ уровней**: Support/Resistance, Fibonacci, Fractals
- **Анализ паттернов**: Свечные паттерны, графические паттерны
- **Анализ структуры**: Высшие максимумы/минимумы, микроструктура
- **Временной анализ**: Сессии, дни недели
- **Корреляционный анализ**: Связи между индикаторами

### 3. Прогнозирование
- Расчет вероятности импульса (0-100%)
- Определение типа сигнала (Boom/Crash)
- Прогнозирование времени появления (1-3 бара)
- Оценка уровня уверенности

### 4. Самообучение
- Сбор исторических данных для обучения
- Обновление весов машинного обучения
- Адаптация к изменяющимся рыночным условиям

## Интерпретация сигналов

### 🔵 Boom Signal (Синий)
- **Условия**: Восходящий тренд + высокий моментум + высокий объем
- **Вероятность**: >70% (настраивается)
- **Время**: 1-3 бара до импульса
- **Действие**: Ожидание резкого роста цены

### 🔴 Crash Signal (Красный)
- **Условия**: Нисходящий тренд + высокий моментум + высокий объем  
- **Вероятность**: >70% (настраивается)
- **Время**: 1-3 бара до импульса
- **Действие**: Ожидание резкого падения цены

## Устранение неполадок

### Ошибки компиляции
- Убедитесь, что файл `CrashBoom_AdvancedAnalysis.mqh` находится в папке `MQL5/Include/`
- Проверьте версию MetaTrader 5 (должна быть актуальной)
- Убедитесь, что все встроенные индикаторы доступны

### Отсутствие сигналов
- Проверьте настройки чувствительности (SpikePredictionSensitivity)
- Убедитесь, что символ поддерживается
- Проверьте достаточность исторических данных (минимум 100 баров)

### Неточные сигналы
- Включите самообучение (EnableMachineLearning = true)
- Увеличьте период обучения (LearningPeriod)
- Настройте чувствительность под ваш стиль торговли
