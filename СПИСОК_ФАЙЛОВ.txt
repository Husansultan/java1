КАК НАЙТИ ФАЙЛЫ В CURSOR?
═══════════════════════════════════════════════════════════════════

1. Посмотрите в ЛЕВУЮ боковую панель Cursor
   (обычно там значок 📁 или "Explorer")

2. Вы должны увидеть все эти файлы в списке

3. Способы скопировать файл:
   
   ► Правой кнопкой → "Copy Path" (скопировать путь)
   ► Правой кнопкой → "Reveal in File Explorer" (открыть в проводнике)
   ► Правой кнопкой → "Copy" (копировать)
   ► Открыть файл → Ctrl+A → Ctrl+C (скопировать содержимое)

═══════════════════════════════════════════════════════════════════
КУДА КОПИРОВАТЬ ФАЙЛЫ .MQ5?
═══════════════════════════════════════════════════════════════════

Для MetaTrader 5 скопируйте .mq5 файлы в:

Windows:
C:\Users\[ВашеИмя]\AppData\Roaming\MetaQuotes\Terminal\[ID]\MQL5\Indicators\

Быстрый способ найти папку:
1. Откройте MT5
2. File → Open Data Folder
3. Перейдите в MQL5\Indicators\
4. Скопируйте сюда файл .mq5

═══════════════════════════════════════════════════════════════════
ПОРЯДОК ДЕЙСТВИЙ ПОСЛЕ СКАЧИВАНИЯ:
═══════════════════════════════════════════════════════════════════

Шаг 1: Скачайте файлы на диск C:\
        (в любую папку, например C:\CrashBoom\)

Шаг 2: Скопируйте .mq5 файл в папку MT5 Indicators
        (см. раздел выше)

Шаг 3: Откройте MetaEditor (F4 в MT5)

Шаг 4: Откройте файл .mq5

Шаг 5: Нажмите F7 (Compile)

Шаг 6: Добавьте индикатор на график
        Navigator → Indicators → Custom → CrashBoom_Simple

Шаг 7: Настройте параметры и торгуйте!

НУЖНА ПОМОЩЬ?
═══════════════════════════════════════════════════════════════════

Если не можете найти файлы в Cursor:

1. Убедитесь, что открыта папка /workspace/
   (посмотрите вверху окна Cursor)

2. Обновите панель Explorer (F5 или кнопка обновить)

3. Попробуйте открыть файл через меню:
   File → Open File → найдите /workspace/CrashBoom_Simple.mq5

4. Используйте поиск в Cursor (Ctrl+P):
   Введите "CrashBoom" и выберите нужный файл
