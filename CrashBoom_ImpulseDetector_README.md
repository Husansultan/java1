# CrashBoom Impulse Detector для MetaTrader 5

## Описание
Профессиональный индикатор для анализа синтетических индексов Crash/Boom от брокера Deriv. Использует комплексный технический анализ с элементами машинного обучения для предсказания импульсов (спайков).

## Основные возможности

### 🎯 Технический анализ
- **Скользящие средние**: EMA 50/100/200 для определения тренда
- **Осцилляторы**: RSI, MACD, Stochastic для поиска разворотов
- **Волатильность**: ATR, Bollinger Bands для оценки рыночных условий
- **Bill Williams**: Alligator, Awesome Oscillator, Accelerator, Fractals
- **Дополнительные**: CCI, Momentum, Williams %R, ZigZag

### 📊 Графические объекты
- Автоматическое построение уровней Фибоначчи
- Динамические линии тренда
- Уровни поддержки и сопротивления
- Очистка устаревших объектов

### 🤖 Самообучение
- Адаптивные веса сигналов на основе исторической точности
- Статистика прогнозов в реальном времени
- Автоматическая оптимизация параметров

### 🔔 Система оповещений
- Звуковые сигналы (Alert)
- Push-уведомления на мобильные устройства
- Email-оповещения
- Защита от спама (минимум 1 минута между сигналами)

## Поддерживаемые символы
```
Crash: 150, 300, 500, 600, 900, 1000 Index
Boom:  150, 300, 500, 600, 900, 1000 Index
```

## Установка

1. **Скопируйте файл** `CrashBoom_ImpulseDetector.mq5` в папку:
   ```
   MetaTrader 5/MQL5/Indicators/
   ```

2. **Откройте MetaEditor** и скомпилируйте индикатор (F7)

3. **Перезапустите MetaTrader 5**

4. **Добавьте индикатор** на график символа Crash/Boom:
   - Навигатор → Индикаторы → Пользовательские → CrashBoom_ImpulseDetector

## Настройка параметров

### Основные настройки
- `SpikeDetectionDepth` (20) - Глубина анализа фракталов
- `SpikePredictionSensitivity` (0.75) - Чувствительность (0.1-1.0)
- `AnalysisTimeframe` - Таймфрейм для анализа

### Скользящие средние
- `MovingAveragePeriod1/2/3` - Периоды EMA (50/100/200)
- `MA_Method` - Метод расчета (EMA рекомендуется)

### Осцилляторы
- `RSI_Period` (14) - Период RSI
- `MACD_Fast/Slow/Signal` (12/26/9) - Параметры MACD
- `Stoch_K/D/Slowing` (5/3/3) - Настройки Stochastic

### Визуализация
- `ShowFibonacciLevels` - Показывать уровни Фибоначчи
- `ShowTrendLines` - Отображать линии тренда
- `ArrowSize/Distance` - Размер и позиция стрелок
- `BuyArrowColor/SellArrowColor` - Цвета сигналов

### Оповещения
- `EnableAlerts` - Звуковые сигналы
- `EnablePushNotifications` - Push на телефон
- `EnableEmailAlerts` - Email уведомления
- `AlertSoundFile` - Файл звука ("alert.wav")

### Самообучение
- `EnableSelfLearning` - Включить адаптацию
- `LearningHistoryBars` (1000) - Количество баров для обучения
- `LearningRate` (0.01) - Скорость обучения

## Интерпретация сигналов

### 🔵 Синие стрелки (Boom)
- Появляются **ДО** ожидаемого импульса вверх
- Показывают потенциальные точки роста цены
- Лучше работают на символах Boom Index

### 🔴 Красные стрелки (Crash)
- Появляются **ДО** ожидаемого импульса вниз  
- Показывают потенциальные точки падения цены
- Лучше работают на символах Crash Index

### 📊 Информационная панель
Отображает в реальном времени:
- Направление текущего тренда
- Значения RSI и ATR
- Точность прогнозов системы самообучения

## Устранение неполадок

### Индикатор не отображает сигналы
1. Проверьте, что символ содержит "Crash" или "Boom"
2. Убедитесь в наличии достаточной истории (100+ баров)
3. Снизьте параметр `SpikePredictionSensitivity`

### Не работают оповещения
1. Включите параметр `EnableAlerts`
2. Проверьте настройки звука в MT5
3. Для Push: включите уведомления в настройках MT5

### Низкая точность прогнозов
1. Дайте системе время на обучение (500+ баров)
2. Настройте параметр `LearningRate`
3. Используйте оптимальные таймфреймы для вашего стиля
