# Руководство по установке CrashBoom Impulse Detector

## Быстрая установка (5 минут)

### Шаг 1: Подготовка файлов
1. Скачайте файл `CrashBoom_ImpulseDetector.mq5` из этого репозитория
2. Убедитесь, что у вас установлен MetaTrader 5

### Шаг 2: Копирование файла

#### Вариант А: Через MetaEditor (рекомендуется)
1. Откройте MetaTrader 5
2. Нажмите **F4** или перейдите в меню **Сервис → Редактор MetaQuotes Language**
3. В MetaEditor нажмите **Файл → Открыть папку данных**
4. Перейдите в папку **MQL5 → Indicators**
5. Скопируйте файл `CrashBoom_ImpulseDetector.mq5` в эту папку

#### Вариант Б: Ручное копирование
1. Нажмите **Win + R** и введите: `%APPDATA%\MetaQuotes\Terminal`
2. Откройте папку с длинным именем (например, `D0E8209F77C8CF37AD8BF550E51FF075`)
3. Перейдите в **MQL5 → Indicators**
4. Скопируйте файл `CrashBoom_ImpulseDetector.mq5` сюда

### Шаг 3: Компиляция
1. Откройте MetaEditor (F4 в MT5)
2. В Navigator слева найдите **Indicators → CrashBoom_ImpulseDetector.mq5**
3. Дважды кликните на файл для открытия
4. Нажмите **F7** или кнопку **Compile** на панели инструментов
5. Проверьте вкладку **Toolbox → Errors** внизу:
   - ✅ **"0 error(s), 0 warning(s)"** - компиляция успешна!
   - ❌ Если есть ошибки - см. раздел "Устранение неполадок" ниже

### Шаг 4: Применение на график
1. Вернитесь в MetaTrader 5
2. Откройте график нужного символа:
   - Crash 300 Index
   - Crash 500 Index
   - Crash 1000 Index
   - Boom 1000 Index
   - или любой другой Crash/Boom
3. Перейдите в меню **Вставка → Индикаторы → Пользовательские → CrashBoom_ImpulseDetector**
4. Или перетащите индикатор из **Navigator → Indicators → Custom** на график

### Шаг 5: Настройка параметров
1. В открывшемся окне настроек вы увидите множество параметров
2. Для начала можете использовать **настройки по умолчанию**
3. Обязательно включите:
   - ✅ **EnableAlerts = true** (оповещения)
   - ✅ **ShowInfoPanel = true** (информационная панель)
   - ✅ **ShowFibonacciLevels = true** (уровни Фибоначчи)
   - ✅ **ShowSupportResistance = true** (уровни S/R)
4. Нажмите **OK**

### Шаг 6: Проверка работы
После применения индикатора вы должны увидеть:
- 📊 **Информационную панель** в левом верхнем углу графика
- 📈 **Уровни Fibonacci** (золотистые пунктирные линии)
- 🟢🔴 **Уровни поддержки/сопротивления** (зеленые и красные линии)
- ⬆️⬇️ **Стрелки сигналов** (при обнаружении вероятных импульсов)

## Настройка уведомлений

### Push-уведомления на смартфон
1. Установите приложение **MetaTrader 5** на смартфон (iOS/Android)
2. В приложении перейдите в **Настройки → Чат и сообщения**
3. Скопируйте **MetaQuotes ID**
4. В MT5 на компьютере: **Сервис → Настройки → Уведомления**
5. Включите **Разрешить push-уведомления**
6. Вставьте ваш **MetaQuotes ID**
7. Нажмите **Тест** для проверки
8. В настройках индикатора: **EnablePushNotifications = true**

### Email-уведомления
1. В MT5: **Сервис → Настройки → Email**
2. Включите **Разрешить**
3. Заполните:
   - **SMTP сервер**: smtp.gmail.com:587 (для Gmail)
   - **SMTP логин**: ваш email
   - **SMTP пароль**: пароль приложения (не обычный пароль!)
   - **От**: ваш email
   - **Кому**: email для получения уведомлений
4. Нажмите **Тест**
5. В настройках индикатора: **EnableEmailNotifications = true**

#### Для Gmail нужно создать пароль приложения:
1. Перейдите на https://myaccount.google.com/security
2. Включите **двухфакторную аутентификацию**
3. Перейдите в **Пароли приложений**
4. Создайте новый пароль для "Другое приложение"
5. Используйте этот пароль в настройках MT5

## Рекомендованные настройки

### Для начинающих (консервативная стратегия)
```
SpikePredictionSensitivity = 0.70  // Высокая точность, меньше сигналов
EnableAlerts = true
ShowInfoPanel = true
ShowFibonacciLevels = true
ShowSupportResistance = true
EnableSelfLearning = true
```

### Для опытных трейдеров (агрессивная стратегия)
```

EnableAlerts = true
ShowInfoPanel = true
ShowFibonacciLevels = true
ShowSupportResistance = true
EnableSelfLearning = true
LearningRate = 0.15  // Быстрое обучение
```

### Для скальпинга (M1-M5)
```
Timeframe = PERIOD_M1
SpikePredictionSensitivity = 0.65
SpikeDetectionDepth = 50
MovingAveragePeriod1 = 20
MovingAveragePeriod2 = 50
MovingAveragePeriod3 = 100
RSI_Period = 9
EnableAlerts = true
EnablePushNotifications = true  // Важно для быстрых сигналов
```

### Для среднесрочной торговли (M15-H1)
```
Timeframe = PERIOD_M15
SpikePredictionSensitivity = 0.70
SpikeDetectionDepth = 100
MovingAveragePeriod1 = 50
MovingAveragePeriod2 = 100
MovingAveragePeriod3 = 200
RSI_Period = 14
EnableAlerts = true
```

## Устранение неполадок

### Ошибка компиляции: "undeclared identifier"
**Решение**: Убедитесь, что используется MT5 (а не MT4). Индикатор написан на MQL5.

### Ошибка: "cannot open file"
**Решение**: 
1. Проверьте путь к файлу
2. Убедитесь, что файл сохранен с расширением .mq5
3. Закройте и откройте MetaEditor заново

### Индикатор не отображается в списке
**Решение**:
1. Обновите список индикаторов: в Navigator кликните правой кнопкой → Refresh
2. Перезапустите MT5
3. Проверьте, что компиляция прошла успешно (0 errors)

### Индикатор не показывает сигналы
**Решение**:
1. Проверьте, что символ содержит "Crash" или "Boom" в названии
2. Дождитесь загрузки минимум 200 свечей истории
3. Попробуйте снизить **SpikePredictionSensitivity** до 0.50
4. Проверьте журнал (Toolbox → Journal) на наличие ошибок

### Слишком много сигналов / ложные сигналы
**Решение**:
1. Увеличьте **SpikePredictionSensitivity** до 0.70-0.80
2. Используйте больший таймфрейм (M5, M15, H1)
3. Включите **EnableSelfLearning = true** и подождите накопления статистики
4. Используйте индикатор в комплексе с другими методами анализа

### Индикатор "тормозит" график
**Решение**:
1. Уменьшите **SpikeDetectionDepth** до 50
2. Отключите **ShowFibonacciLevels = false**
3. Отключите **ShowSupportResistance = false**
4. Закройте другие ресурсоемкие индикаторы
5. Используйте больший таймфрейм

### Push-уведомления не приходят
**Решение**:
1. Проверьте интернет-соединение
2. Убедитесь, что MT5 подключен к серверу (зеленая иконка в правом нижнем углу)
3. Проверьте правильность MetaQuotes ID
4. Протестируйте уведомления через Сервис → Настройки → Уведомления → Тест
5. Перезапустите MT5

### Email-уведомления не приходят
**Решение**:
1. Проверьте правильность настроек SMTP
2. Для Gmail используйте пароль приложения (не обычный пароль!)
3. Проверьте папку "Спам" в почте
4. Протестируйте через Сервис → Настройки → Email → Тест
5. Попробуйте другой SMTP-сервер:
   - Gmail: smtp.gmail.com:587
   - Outlook: smtp-mail.outlook.com:587
   - Yahoo: smtp.mail.yahoo.com:587

## Проверка работы индикатора

### Быстрый тест
1. Примените индикатор на график Crash 500 Index, M5
2. Подождите 2-3 минуты
3. Проверьте наличие:
   - ✅ Информационной панели
   - ✅ Уровней Fibonacci
   - ✅ Зеленых/красных линий S/R
   - ✅ Записей в журнале (Toolbox → Journal): "Индикатор CrashBoom_ImpulseDetector успешно инициализирован"

### Тест оповещений
1. В настройках индикатора установите **SpikePredictionSensitivity = 0.30** (очень низкая чувствительность)
2. Дождитесь сигнала (должен появиться в течение 5-10 минут)
3. Проверьте:
   - 🔊 Звуковое оповещение
   - 📱 Alert-сообщение
   - 📊 Стрелка на графике
4. Верните **SpikePredictionSensitivity = 0.65**

### Тест на истории (бэктестинг)
1. Прокрутите график назад на несколько часов/дней
2. Найдите реальные импульсы (большие свечи)
3. Проверьте, показывал ли индикатор сигналы за 1-5 свечей до импульса
4. Оцените точность предсказаний

## Советы по использованию

### ✅ Лучшие практики
- Используйте индикатор на нескольких таймфреймах одновременно
- Комбинируйте сигналы с Price Action анализом
- Ведите журнал сделок для анализа эффективности
- Дайте время самообучению (минимум 100 сигналов)
- Используйте стоп-лоссы и тейк-профиты
- Не рискуйте более 1-2% капитала на одну сделку

### ⚠️ Чего избегать
- Не торгуйте только по сигналам индикатора
- Не используйте максимальный леверидж
- Не игнорируйте фундаментальные факторы
- Не торгуйте во время новостей высокой важности
- Не меняйте настройки после каждого убытка
- Не ожидайте 100% точности (это невозможно)

## Часто задаваемые вопросы (FAQ)

**Q: Работает ли индикатор на MT4?**
A: Нет, индикатор написан на MQL5 и работает только в MetaTrader 5.

**Q: Можно ли использовать на других символах (не Crash/Boom)?**
A: Технически да, но индикатор оптимизирован именно для Crash/Boom. На других символах эффективность может быть ниже.

**Q: Сколько времени нужно для самообучения?**
A: Рекомендуется минимум 100-200 сигналов (примерно 1-2 недели работы).

**Q: Можно ли использовать на реальном счете?**
A: Сначала протестируйте на демо-счете минимум 2-4 недели, чтобы изучить работу индикатора.

**Q: Какой минимальный депозит нужен?**
A: Зависит от вашего риск-менеджмента. Рекомендуется минимум $100 для Crash/Boom индексов.

**Q: Гарантирует ли индикатор прибыль?**
A: Нет. Ни один индикатор не может гарантировать прибыль. Всегда существует риск убытков.

**Q: Как часто обновляется индикатор?**
A: Индикатор обновляет расчеты на каждом новом тике/свече.

**Q: Можно ли запустить несколько копий индикатора?**
A: Да, можно применить на разные графики с разными настройками.

**Q: Потребляет ли индикатор много ресурсов?**
A: При настройках по умолчанию - умеренное потребление. Для слабых ПК рекомендуется уменьшить SpikeDetectionDepth.

**Q: Работает ли индикатор в выходные?**
A: Синтетические индексы Deriv торгуются 24/7, поэтому индикатор работает всегда.
