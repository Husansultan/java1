# CrashBoom Impulse Detector - Руководство по установке и использованию

## Описание
**CrashBoom_ImpulseDetector.mq5** - это профессиональный индикатор для MetaTrader 5, специально разработанный для анализа и прогнозирования импульсов (спайков) на синтетических индексах Crash и Boom от брокера Deriv.

## Основные возможности

### 🎯 Комплексный технический анализ
- **13+ технических индикаторов**: RSI, MACD, Stochastic, Williams %R, CCI, Momentum, ATR, Bollinger Bands, и другие
- **Трендовые индикаторы**: EMA (50, 100, 200), Ichimoku, Parabolic SAR, Alligator
- **Объемный анализ**: OBV, MFI, анализ тиковых объемов
- **Графические паттерны**: Фракталы, ZigZag, уровни поддержки/сопротивления

### 🤖 Система самообучения
- Адаптивные алгоритмы машинного обучения
- Автоматическая корректировка весов на основе исторических данных
- Повышение точности прогнозов со временем

### 🎨 Визуализация
- Цветные стрелки для сигналов (🔴 Crash / 🔵 Boom)
- Информационная панель в реальном времени
- Настраиваемые размеры и цвета стрелок

### 🔔 Система оповещений
- Звуковые сигналы (Alert)
- Push-уведомления на мобильные устройства
- Email-уведомления (опционально)
- Защита от спама (не чаще 1 раза в минуту)

## Установка

### Шаг 1: Подготовка файлов
1. Скачайте файл `CrashBoom_ImpulseDetector.mq5`
2. Откройте MetaTrader 5
3. Нажмите `Ctrl+Shift+D` или перейдите в `Файл → Открыть папку данных`

### Шаг 2: Копирование файла
1. В открывшейся папке перейдите в `MQL5 → Indicators`
2. Скопируйте файл `CrashBoom_ImpulseDetector.mq5` в эту папку

### Шаг 3: Компиляция
1. В MetaTrader 5 нажмите `F4` или перейдите в `Инструменты → Редактор MetaQuotes Language`
2. В MetaEditor откройте файл `CrashBoom_ImpulseDetector.mq5`
3. Нажмите `F7` или `Compile` для компиляции
4. Убедитесь, что компиляция прошла без ошибок

### Шаг 4: Применение индикатора
1. Откройте график любого индекса Crash или Boom
2. В навигаторе найдите `CrashBoom_ImpulseDetector` в разделе "Индикаторы"
3. Перетащите индикатор на график или дважды кликните по нему

## Настройка параметров

### Основные параметры
- **SpikeDetectionDepth** (20) - Глубина анализа фракталов
- **SpikePredictionSensitivity** (0.75) - Чувствительность (0.1-1.0)
- **AnalysisTimeframe** - Таймфрейм для анализа

### Скользящие средние
- **MovingAveragePeriod1/2/3** (50/100/200) - Периоды EMA
- **MA_Method** - Метод расчета (EMA рекомендуется)

### Осцилляторы
- **RSI_Period** (14) - Период RSI
- **MACD_Fast/Slow/Signal** (12/26/9) - Параметры MACD
- **Stoch_K/D/Slowing** (5/3/3) - Параметры Stochastic

### Волатильность
- **ATR_Period** (14) - Период ATR
- **BB_Period** (20) - Период Bollinger Bands
- **BB_Deviation** (2.0) - Отклонение BB

### Визуализация
- **ArrowSize** (3) - Размер стрелок
- **ArrowDistance** (20) - Расстояние от свечи
- **CrashArrowColor/BoomArrowColor** - Цвета стрелок
- **ShowInfoPanel** (true) - Показать информационную панель

### Оповещения
- **EnableAlerts** (true) - Звуковые сигналы
- **EnablePushNotifications** (false) - Push-уведомления
- **EnableEmailAlerts** (false) - Email-уведомления
- **AlertSoundFile** ("alert.wav") - Звуковой файл

### Самообучение
- **EnableSelfLearning** (true) - Включить самообучение
- **LearningPeriod** (1000) - Период обучения в барах
- **LearningRate** (0.01) - Скорость обучения

## Как работает индикатор

### Алгоритм анализа
1. **Сбор данных** - Получение значений всех технических индикаторов
2. **Комплексный анализ** - Взвешенная оценка всех сигналов
3. **Машинное обучение** - Корректировка весов на основе истории
4. **Прогнозирование** - Расчет вероятности импульса
5. **Сигнализация** - Отображение стрелок и отправка уведомлений

### Критерии для Crash сигналов (🔴)
- RSI > 70 (перекупленность)
- Цена выше всех скользящих средних
- Медвежья дивергенция MACD
- Цена у верхней полосы Bollinger Bands
- Повышенная волатильность (ATR)
- Фрактальные максимумы
- Перекупленность Stochastic и Williams %R

### Критерии для Boom сигналов (🔵)
- RSI < 30 (перепроданность)
- Цена ниже всех скользящих средних
- Бычья дивергенция MACD
- Цена у нижней полосы Bollinger Bands
- Повышенная волатильность (ATR)
- Фрактальные минимумы
- Перепроданность Stochastic и Williams %R

## Рекомендации по использованию

### Оптимальные настройки
- **Таймфрейм**: M1-M5 для скальпинга, M15-H1 для среднесрочной торговли
- **Чувствительность**: 0.6-0.8 для начинающих, 0.4-0.6 для опытных трейдеров
- **Самообучение**: Обязательно включить для повышения точности

### Стратегия торговли
1. Дождитесь появления стрелки на графике
2. Подтвердите сигнал дополнительным анализом
3. Входите в позицию в направлении прогнозируемого импульса
4. Используйте стоп-лосс и тейк-профит
5. Не торгуйте против основного тренда

### Управление рисками
- Не рискуйте более 2% депозита на сделку
- Используйте стоп-лосс на каждой позиции
- Не торгуйте во время важных новостей
- Учитывайте особенности синтетических индексов

### Устранение неполадок

**Проблема**: Индикатор не отображает стрелки
**Решение**: 
- Проверьте правильность символа (должен быть Crash/Boom)
- Убедитесь в наличии достаточной истории (минимум 200 баров)
- Проверьте настройки чувствительности

**Проблема**: Не работают оповещения
**Решение**:
- Включите параметр EnableAlerts
- Проверьте настройки звука в MT5
- Для Push-уведомлений настройте MetaQuotes ID

**Проблема**: Высокая нагрузка на CPU
**Решение**:
- Отключите самообучение на слабых компьютерах
- Увеличьте таймфрейм анализа
- Закройте ненужные графики
