# 🎯 CrashBoom Impulse Detector для MT5

## Описание
Профессиональный индикатор для MetaTrader 5, предназначенный для предсказания импульсов (спайков) на синтетических индексах **Crash** и **Boom** от брокера **Deriv**.

## ✨ Основные Возможности

### 📊 Комплексный Технический Анализ
- ✅ **20+ технических индикаторов**: MA, RSI, MACD, Bollinger Bands, Stochastic, CCI, Williams %R, MFI, ADX, Ichimoku, Parabolic SAR, и многие другие
- ✅ **Анализ трендов**: Определение направления рынка по нескольким скользящим средним
- ✅ **Анализ волатильности**: ATR, Bollinger Bands для оценки рыночных условий
- ✅ **Определение дивергенций**: RSI и MACD дивергенции для поиска разворотов
- ✅ **Фрактальный анализ**: Fractals и ZigZag для определения ключевых уровней

### 🧠 Искусственный Интеллект
- ✅ **Система самообучения**: Автоматическая коррекция весов индикаторов
- ✅ **Адаптивность**: Улучшение точности предсказаний со временем
- ✅ **Анализ исторических данных**: Обучение на основе прошлых импульсов

### 🎯 Предсказание Импульсов
- ✅ **Раннее предупреждение**: Сигналы за 1-5 свечей до импульса
- ✅ **Настраиваемая чувствительность**: Контроль частоты и точности сигналов
- ✅ **Автоопределение типа символа**: Автоматически распознает Crash/Boom

### 📱 Система Уведомлений
- ✅ **Звуковые оповещения**: Alert при появлении сигнала
- ✅ **Push-уведомления**: На мобильное приложение MT5
- ✅ **Email-уведомления**: На электронную почту
- ✅ **Визуальные сигналы**: Стрелки и информационная панель на графике

### 📈 Визуализация
- ✅ **Цветные стрелки**: Синие для Boom (вверх), красные для Crash (вниз)
- ✅ **Информационная панель**: Отображение текущего состояния всех индикаторов
- ✅ **Процент вероятности**: Показывает силу сигнала в процентах
- ✅ **Отображение тренда**: UP/DOWN/SIDEWAYS с цветовой индикацией

## 🚀 Быстрый Старт

### 1. Установка
```
1. Скопируйте файл CrashBoom_ImpulseDetector.mq5 в папку:
   C:\Users\[Ваше_имя]\AppData\Roaming\MetaQuotes\Terminal\[ID]\MQL5\Indicators\

2. Откройте MetaEditor (F4) и скомпилируйте файл (F7)

3. Перезапустите MetaTrader 5
```

### 2. Применение на график
```
1. Откройте график Crash или Boom индекса
2. В Навигаторе найдите: Indicators → Custom → CrashBoom_ImpulseDetector
3. Перетащите на график
4. Настройте параметры и нажмите OK
```

### 3. Первая настройка
Рекомендуемые параметры для начинающих:
- **SpikePredictionSensitivity**: 0.65 (баланс между частотой и точностью)
- **EnableAlerts**: true (включить звуковые сигналы)
- **ShowInfoPanel**: true (показывать панель информации)
- **EnableLearning**: true (включить самообучение)

## 🎓 Как Использовать

### Для индексов Crash:
1. Ждите появления **красной стрелки вниз** ⬇️
2. Проверьте информационную панель: Signal должен быть **SELL**
3. Убедитесь, что Probability > 65%
4. Откройте **SELL** позицию
5. Установите Stop Loss выше последнего максимума
6. Ожидайте импульс вниз (резкое падение цены)

### Для индексов Boom:
1. Ждите появления **синей стрелки вверх** ⬆️
2. Проверьте информационную панель: Signal должен быть **BUY**
3. Убедитесь, что Probability > 65%
4. Откройте **BUY** позицию
5. Установите Stop Loss ниже последнего минимума
6. Ожидайте импульс вверх (резкий рост цены)

## ⚙️ Настройка Параметров

### Основные параметры
| Параметр | Значение | Описание |
|----------|----------|----------|
| **SpikePredictionSensitivity** | 0.50-0.90 | Чем выше - тем реже, но точнее сигналы |
| **EnableLearning** | true | Включить самообучение для улучшения точности |
| **PredictionBarsAhead** | 1-5 | За сколько свечей предупреждать |

### Для агрессивной торговли (больше сигналов)
- SpikePredictionSensitivity: **0.50-0.60**
- Используйте на таймфрейме **M1** или **M5**
- Подходит для Crash/Boom 300 и 500

### Для консервативной торговли (точнее сигналы)
- SpikePredictionSensitivity: **0.75-0.85**
- Используйте на таймфрейме **M15** или **M30**
- Подходит для Crash/Boom 900 и 1000

## 🔧 Устранение Проблем

### Нет сигналов
✅ Снизьте SpikePredictionSensitivity до 0.5-0.6
✅ Проверьте, что рынок не в боковике
✅ Увеличьте историю данных (загрузите больше баров)

### Слишком много ложных сигналов
✅ Повысьте SpikePredictionSensitivity до 0.75-0.85
✅ Используйте старший таймфрейм (M15 вместо M5)
✅ Включите самообучение и дайте время на адаптацию

### Индикатор не загружается
✅ Проверьте компиляцию (должно быть 0 errors)
✅ Убедитесь, что используете символы Deriv (Crash/Boom)
✅ Проверьте логи в терминале (вкладка Experts)
