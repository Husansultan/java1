# CrashBoom Impulse Detector - Полная документация

## Описание
Комплексный пользовательский индикатор для MetaTrader 5, предназначенный для анализа и прогнозирования импульсов (спайков) на синтетических индексах Deriv Crash и Boom.

## Поддерживаемые символы
- **Crash индексы**: Crash 150, 300, 500, 600, 900, 1000 Index
- **Boom индексы**: Boom 150, 300, 500, 600, 900, 1000 Index

## Основные возможности

### 1. Комплексный технический анализ
Индикатор использует более 20 технических инструментов:

#### Трендовые индикаторы:
- Moving Average (EMA 50, 100, 200)
- Bollinger Bands
- Parabolic SAR
- Ichimoku Kinko Hyo
- Alligator (Bill Williams)

#### Осцилляторы:
- RSI (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)
- Stochastic Oscillator
- CCI (Commodity Channel Index)
- Williams %R
- Momentum
- Awesome Oscillator (AO)
- Accelerator Oscillator (AC)

#### Объемные индикаторы:
- On Balance Volume (OBV)
- Money Flow Index (MFI)

#### Волатильность:
- ATR (Average True Range)
- Bollinger Bands

#### Графические инструменты:
- Fibonacci Retracement
- Уровни поддержки и сопротивления
- Фрактальный анализ

### 2. Алгоритм предсказания импульсов

Индикатор анализирует рыночные условия по 15 критериям с весовыми коэффициентами:

1. **Скользящие средние (10%)** - определение направления тренда
2. **RSI (15%)** - зоны перекупленности/перепроданности
3. **MACD (12%)** - пересечения и дивергенции
4. **Bollinger Bands (10%)** - выход за границы диапазона
5. **Stochastic (8%)** - экстремальные значения
6. **CCI (7%)** - сильные отклонения
7. **Williams %R (6%)** - перекупленность/перепроданность
8. **Momentum (5%)** - изменение скорости движения
9. **Alligator (7%)** - положение цены относительно линий
10. **Parabolic SAR (5%)** - точки разворота
11. **Ichimoku (6%)** - пересечения линий
12. **MFI (5%)** - денежный поток
13. **Awesome Oscillator (4%)** - моментум
14. **Accelerator Oscillator (4%)** - ускорение
15. **ATR (6%)** - волатильность

Итоговая вероятность импульса рассчитывается как взвешенная сумма всех факторов.

### 3. Самообучение

Индикатор отслеживает историю своих прогнозов и корректирует алгоритм на основе:
- Фактических результатов после сигналов
- Точности предыдущих прогнозов
- Адаптивной корректировки чувствительности

### 4. Визуализация

#### Стрелки на графике:
- 🔵 **Синяя стрелка вверх** - ожидается импульс роста (Boom)
- 🔴 **Красная стрелка вниз** - ожидается импульс падения (Crash)

#### Информационная панель:
Отображает в реальном времени:
- Текущий тренд (восходящий/нисходящий/боковой)
- Вероятность импульса (в процентах)
- Тип символа (Crash/Boom)
- Текущие значения RSI, ATR, MACD

#### Графические объекты:
- Уровни Fibonacci (0%, 23.6%, 38.2%, 50%, 61.8%, 78.6%, 100%)
- Уровни поддержки (зеленые линии)
- Уровни сопротивления (красные линии)

### 5. Система оповещений

При обнаружении вероятного импульса индикатор:
- ✅ Показывает стрелку на графике за 1-5 свечей до импульса
- 🔊 Воспроизводит звуковой сигнал
- 📱 Отправляет Push-уведомление (опционально)
- 📧 Отправляет Email-уведомление (опционально)
- 💬 Выводит Alert-сообщение

## Установка

1. Скопируйте файл `CrashBoom_ImpulseDetector.mq5` в папку:
   ```
   C:\Users\[ИМЯ_ПОЛЬЗОВАТЕЛЯ]\AppData\Roaming\MetaQuotes\Terminal\[ID_ТЕРМИНАЛА]\MQL5\Indicators\
   ```

2. Откройте MetaEditor (F4 в MT5)

3. Найдите файл в Navigator → Indicators

4. Нажмите Compile (F7)

5. После успешной компиляции индикатор появится в списке пользовательских индикаторов MT5

## Применение на график

1. В MT5 откройте график нужного символа (Crash или Boom)
2. Вставка → Индикаторы → Пользовательские → CrashBoom_ImpulseDetector
3. Настройте параметры (или используйте по умолчанию)
4. Нажмите OK

## Настройка параметров

### Общие настройки
- **Timeframe** - таймфрейм для анализа (по умолчанию: текущий)
- **SpikeDetectionDepth** - глубина анализа в свечах (по умолчанию: 100)
- **SpikePredictionSensitivity** - чувствительность прогноза 0-1 (по умолчанию: 0.65)
  - 0.5 - средняя чувствительность
  - 0.7 - высокая чувствительность (меньше сигналов, выше точность)
  - 0.4 - низкая чувствительность (больше сигналов, ниже точность)
- **EnableAlerts** - включить звуковые оповещения
- **EnablePushNotifications** - включить Push-уведомления
- **EnableEmailNotifications** - включить Email-уведомления

### Скользящие средние
- **MovingAveragePeriod1** - период EMA 1 (по умолчанию: 50)
- **MovingAveragePeriod2** - период EMA 2 (по умолчанию: 100)
- **MovingAveragePeriod3** - период EMA 3 (по умолчанию: 200)
- **MA_Method** - метод расчета MA (EMA, SMA, SMMA, LWMA)

### Осцилляторы
- **RSI_Period** - период RSI (по умолчанию: 14)
- **MACD_Fast** - быстрая линия MACD (по умолчанию: 12)
- **MACD_Slow** - медленная линия MACD (по умолчанию: 26)
- **MACD_Signal** - сигнальная линия MACD (по умолчанию: 9)
- **Stochastic_K** - период %K Stochastic (по умолчанию: 5)
- **Stochastic_D** - период %D Stochastic (по умолчанию: 3)
- **CCI_Period** - период CCI (по умолчанию: 14)
- **WPR_Period** - период Williams %R (по умолчанию: 14)
- **Momentum_Period** - период Momentum (по умолчанию: 14)

### Волатильность
- **ATR_Period** - период ATR (по умолчанию: 14)
- **BB_Period** - период Bollinger Bands (по умолчанию: 20)
- **BB_Deviation** - отклонение BB (по умолчанию: 2.0)

### Bill Williams

- **Alligator_Lips** - период Lips (по умолчанию: 5)

### Графические объекты

- **ShowSupportResistance** - показывать уровни поддержки/сопротивления
- **ShowTrendLines** - показывать трендовые линии
- **SR_LookbackPeriod** - период анализа S/R (по умолчанию: 50)

### Визуализация
- **ArrowSize** - размер стрелки (по умолчанию: 2)

### Дополнительные индикаторы

## Рекомендации по использованию

### Для Crash индексов:
1. Следите за **красными стрелками вниз** - они указывают на вероятное резкое падение
2. Обращайте внимание на сигналы при RSI > 70 (перекупленность)
3. Используйте таймфреймы M1-M5 для краткосрочной торговли
4. Настройте чувствительность 0.6-0.7 для более надежных сигналов

### Для Boom индексов:
1. Следите за **синими стрелками вверх** - они указывают на вероятный резкий рост
2. Обращайте внимание на сигналы при RSI < 30 (перепроданность)
3. Используйте таймфреймы M1-M5 для краткосрочной торговли
4. Настройте чувствительность 0.6-0.7 для более надежных сигналов

### Общие рекомендации:
- ✅ Используйте индикатор в комплексе с другими методами анализа
- ✅ Проверяйте сигналы на истории (бэктестинг)
- ✅ Начните с демо-счета для изучения работы индикатора
- ✅ Настройте уведомления для своевременного получения сигналов
- ⚠️ Не полагайтесь только на индикатор - используйте риск-менеджмент
- ⚠️ Помните, что прошлые результаты не гарантируют будущих

## Оптимизация параметров

Для оптимизации параметров под конкретный символ:

1. Откройте Strategy Tester (Ctrl+R)
2. Создайте простой EA, который торгует по сигналам индикатора
3. Запустите оптимизацию параметров:
   - SpikePredictionSensitivity (0.5 - 0.8, шаг 0.05)
   - RSI_Period (10 - 20, шаг 2)
   - ATR_Period (10 - 20, шаг 2)
4. Выберите комбинацию с лучшими показателями

## Устранение неполадок

### Индикатор не отображает сигналы:
- Проверьте, что символ содержит "Crash" или "Boom" в названии
- Убедитесь, что достаточно исторических данных (минимум 200 свечей)
- Попробуйте снизить SpikePredictionSensitivity

### Слишком много ложных сигналов:
- Увеличьте SpikePredictionSensitivity до 0.7-0.8
- Используйте большие таймфреймы (M5, M15)
- Включите самообучение (EnableSelfLearning)

### Информационная панель не отображается:
- Проверьте, что ShowInfoPanel = true
- Перезапустите индикатор
- Проверьте, что панель не закрыта другими объектами

### Push/Email уведомления не приходят:
- Настройте Push-уведомления в MT5: Сервис → Настройки → Уведомления
- Для Email: настройте SMTP в MT5: Сервис → Настройки → Email
- Убедитесь, что EnablePushNotifications/EnableEmailNotifications = true

## Структура кода

Индикатор построен по модульной архитектуре:

```
OnInit() - Инициализация индикаторов и параметров
OnDeinit() - Освобождение ресурсов
OnCalculate() - Основной цикл расчета
├── CalculateSpikeProbability() - Расчет вероятности импульса
├── DetermineTrend() - Определение тренда
├── UpdateLearningData() - Обновление данных самообучения
├── DrawFibonacciLevels() - Построение Fibonacci
├── UpdateSupportResistanceLevels() - Обновление S/R
├── UpdateInfoPanel() - Обновление информационной панели
└── SendAlert() - Отправка оповещений
```
