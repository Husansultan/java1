═══════════════════════════════════════════════════════════════════
ШАГ 1: КОПИРОВАНИЕ ФАЙЛОВ
═══════════════════════════════════════════════════════════════════

1. Найдите папку данных MetaTrader 5:
   
   Откройте MT5 → Меню "File" → "Open Data Folder"
   
   Или вручную:
   C:\Users\[Ваше_Имя]\AppData\Roaming\MetaQuotes\Terminal\[ID]\MQL5\Indicators\

2. Скопируйте ОДИН ИЗ файлов в эту папку:
   
   ДЛЯ НАЧИНАЮЩИХ:
   📄 CrashBoom_Simple.mq5
   
   ДЛЯ ОПЫТНЫХ:
   📄 CrashBoom_ImpulseDetector.mq5

═══════════════════════════════════════════════════════════════════
ШАГ 2: КОМПИЛЯЦИЯ В METAEDITOR
═══════════════════════════════════════════════════════════════════

1. Откройте MetaEditor:
   
   В MT5 нажмите F4
   или
   Меню "Tools" → "MetaQuotes Language Editor"

2. Откройте файл индикатора:
   
   В MetaEditor:
   File → Open → найдите файл .mq5
   
   Или двойной клик на файл в Навигаторе MetaEditor

3. Скомпилируйте:
   
   Нажмите F7
   или
   Кнопка "Compile" на панели инструментов
   или
   Меню "File" → "Compile"

4. Проверьте результат компиляции:
   
   Внизу окна MetaEditor должно появиться:
   
   ✅ "0 error(s), 0 warning(s)"  ← ЭТО УСПЕХ!
   
   Если есть ошибки:
   ❌ "X error(s)" ← читайте ошибки внизу

═══════════════════════════════════════════════════════════════════
ШАГ 3: УСТАНОВКА НА ГРАФИК
═══════════════════════════════════════════════════════════════════

1. Откройте график нужного символа:
   
   Crash 500 Index
   или
   Boom 1000 Index
   (или любой другой Crash/Boom индекс от Deriv)

2. Добавьте индикатор на график:
   
   СПОСОБ 1:
   - Откройте Навигатор (Ctrl+N)
   - Раскройте "Indicators" → "Custom"
   - Найдите индикатор (CrashBoom_ImpulseDetector или CrashBoom_Simple)
   - Перетащите мышкой на график
   
   СПОСОБ 2:
   - Меню "Insert" → "Indicators" → "Custom"
   - Выберите индикатор
   - Нажмите OK

3. Настройте параметры:
   
   ДЛЯ НАЧИНАЮЩИХ (первый запуск):
   
   SpikePredictionSensitivity: 65.0
   EnableAlerts: true
   ShowInfoPanel: true
   
   Остальное оставьте по умолчанию.

4. Нажмите OK

═══════════════════════════════════════════════════════════════════
ШАГ 4: ПРОВЕРКА РАБОТЫ
═══════════════════════════════════════════════════════════════════

После установки вы должны увидеть:

✅ Информационную панель в левом верхнем углу графика
   📊 CRASH/BOOM
   Symbol: Crash 500 Index
   Type: CRASH ▼ (или BOOM ▲)
   RSI: XX.X
   Signal: WAIT (или BUY/SELL)

✅ Стрелки на графике:
   - Синие стрелки вверх ⬆ для Boom
   - Красные стрелки вниз ⬇ для Crash

✅ Сообщение в логе (вкладка "Experts" внизу MT5):
   "✅ CrashBoom ... загружен: Crash 500 Index | Тип: CRASH"

═══════════════════════════════════════════════════════════════════
ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════════════

❌ ПРОБЛЕМА: Ошибки компиляции
✅ РЕШЕНИЕ:
   1. Убедитесь, что используете MetaEditor для MT5 (не MT4!)
   2. Обновите MetaTrader 5 до последней версии
   3. Попробуйте упрощённую версию CrashBoom_Simple.mq5

❌ ПРОБЛЕМА: Индикатор не появляется в списке
✅ РЕШЕНИЕ:
   1. Перезапустите MetaTrader 5
   2. Проверьте, что файл скопирован в правильную папку
   3. Убедитесь, что компиляция прошла успешно (0 errors)

❌ ПРОБЛЕМА: На графике ничего не отображается
✅ РЕШЕНИЕ:
   1. Убедитесь, что используете символы Deriv (Crash/Boom)
   2. Загрузите больше истории (нажмите Home, чтобы прокрутить назад)
   3. Снизьте SpikePredictionSensitivity до 50-60
   4. Проверьте логи в терминале (вкладка "Experts")

❌ ПРОБЛЕМА: Нет звуковых сигналов
✅ РЕШЕНИЕ:
   1. Проверьте, что EnableAlerts = true
   2. В MT5: Tools → Options → Audio → включите звуки
   3. Проверьте громкость системы

═══════════════════════════════════════════════════════════════════
ТЕСТИРОВАНИЕ В STRATEGY TESTER
═══════════════════════════════════════════════════════════════════

1. Откройте Strategy Tester (Ctrl+R)

2. Настройте параметры:
   - Indicator: CrashBoom_ImpulseDetector (или Simple)
   - Symbol: Crash 500 Index
   - Period: M5
   - Date: последние 3 месяца
   - Visualization: включить (чтобы видеть стрелки)

3. Нажмите "Start"

4. Наблюдайте за работой индикатора в ускоренном режиме
